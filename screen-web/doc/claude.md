## 项目简介

ScreenX 是一个基于 Vue 3 的数据可视化大屏项目，支持自定义大屏编辑、交互式菜单导航和自适应屏幕缩放。

## 快速开始

```bash

npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```
