# 凡集平台首页资源约定

## 目录

- 统一放在 `src/assets/images/platform/`。
- Logo：`logo-fan.svg`。
- 作品封面：`works/`。
- 漫画封面：`comics/`。
- 电影封面：`movies/`。

## 替换方式

1. 替换现有封面时，保持同名文件即可，页面无需修改。
2. 新增封面时，把文件放入对应子目录，并在 `src/const/platform.js` 里补充数据。
3. 建议作品、漫画和电影封面统一使用 16:9 比例；当前占位图是 `300 x 168`。
4. 正式上线前把占位图替换为压缩后的真实截图或海报，避免把未使用的素材留在项目里。

`logo-fan.svg` 是当前 `FAN` 艺术字初版：几何字形，`A` 的横线向右延伸，形成一条展示线。后续如果要改颜色或造型，建议继续保留 SVG 格式，便于在头部和 favicon 中复用。
