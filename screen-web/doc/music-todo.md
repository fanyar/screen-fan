## 使用方法

### 修改状态

直接编辑此文件，修改对应功能的状态 emoji：

```markdown
# 上班了（开始开发）

❌ 搜索功能 → ⏳ 搜索功能

# 下班了（开发完成）

⏳ 搜索功能 → ✅ 搜索功能
```

### 新增功能

在对应优先级表格中添加新行：

```markdown
| ❌ | 新功能名 | 功能说明 |
```
